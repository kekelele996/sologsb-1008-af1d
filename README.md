# 公共标识多语言校对台

用于公共空间标识译文录入、术语校验、版面风险预览和紧急修订的本地优先工作台。示例包含轨道交通、商场、公园和医院标识。

## 功能

- 录入中文原文、目标语言、适用场景和法规/规范提示。
- 每条标识独立保存预览宽度（320/480/720/960 像素）和字号（28—88 像素），切换标识不再共用、不重设。
- 按场景执行版面标准：轨道交通最低 40px/最多 3 行，商场疏散最低 36px/最多 2 行，公园服务最低 32px/最多 3 行，医院入口最低 34px/最多 2 行；实时统计预计行数并标出超出的行数或缺的字号。
- 为每条标识保存版面验收结果（验收时的宽度、字号、行数、场景标准快照）。译文、目标语言、场景、紧急修订状态变化或场景标准修订后，旧验收自动标记为失效。
- 未达到当前场景标准、验收失效、从未验收或验收未通过的标识不能确认，状态按钮锁定并给出原因。
- 项目页提供「版面未通过」筛选，集中列出验收有效之外的标识，并显示超出的行数、缺的字号或失效原因。
- 统计未命中的必选术语，并给出高风险、需留意、版面安全三级判断。
- 为每条译文绑定固定术语；术语与译文不一致时高亮告警，可逐条确认或删除。
- 支持草稿、待确认、需修改、已确认四种审校状态。
- 添加审校意见、回复并标记解决状态。
- 保存最多 12 个版本快照，按词/字符比较旧版与当前译文，绿色表示新增、红色表示删除。
- 生成只读预览链接；链接读取当前浏览器保存的本地版本，不提供服务端数据。
- 紧急修订模式会让旧验收失效、把已确认标识重置为需修改并锁定确认；重新验收后才能确认。
- 多步撤销/重做、本地自动保存、断网继续编辑。
- 键盘操作：`J`/`K` 切换标识，`[`/`]` 切换预览宽度，`-`/`=` 调整字号。

## 技术栈

- Qwik 1 + Qwik City + TypeScript
- DaisyUI 5 + Tailwind CSS 4
- Qwik City 静态适配器
- 浏览器 `localStorage`
- nginx 静态部署

## 开发

```bash
npm install
npm run dev
```

## 构建与预览

```bash
npm run build
npm run preview
```

生产构建输出到 `dist/`，由 Qwik City static adapter 生成可静态部署文件。

## Docker

容器内 nginx 监听 `80`，宿主端口按根端口表映射为 `10008`。

```bash
docker build -t sologsb-1008 .
docker run --rm -p 10008:80 sologsb-1008
```

访问 `http://localhost:10008`。

## 数据说明

项目和版本数据保存在当前浏览器 `localStorage`。只读预览链接仅对保存过同一浏览器本地数据的设备有效，不回传或公开业务数据。
